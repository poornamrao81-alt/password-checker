# Password Strength Checker 🔐

A beginner-friendly Python project that checks the strength of a password and classifies it as **Low, Medium, or High** based on specific password requirements.

## Project Overview

This program analyzes a password entered by the user and checks different characteristics such as its length, uppercase letters, lowercase letters, numbers, and special characters.

Based on these conditions, the program gives the password a strength level.

## Strength Levels

* **Low** – Password meets only a few basic requirements.
* **Medium** – Password meets several security requirements.
* **High** – Password meets most or all of the required conditions.

## How It Works

1. The user enters a password.
2. The program checks the password against predefined conditions.
3. Each condition contributes to determining the password strength.
4. The program displays the final strength as **Low, Medium, or High**.

## Project Purpose

This project was created as part of my Python learning journey to practice conditional logic, string handling, and analyzing user input while building a practical application.
